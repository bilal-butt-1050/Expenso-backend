# Tech Stack

## Runtime & Frameworks
- **Node.js**: Server runtime.
- **TypeScript**: Static typing (compiles down using `tsc`).
- **Express**: HTTP web framework.

## Database & ORM
- **PostgreSQL**: Primary data store.
- **Prisma**: Type-safe ORM for database modeling and migrations.

## Utilities
- **Zod**: Runtime schema validation.
- **Bcryptjs**: Password hashing.
- **JWT**: Stateless authentication.
- **Resend**: Email delivery.
- **Google Auth Library**: OAuth 2.0 integration.

## Performance Additions
- **Compression**: gzip payload compression.
- **Node-Cache**: LRU in-memory caching.
- **Express Rate Limit**: Basic DDoS mitigation.
